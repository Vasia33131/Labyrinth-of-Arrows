## Об игре

Тапните по стрелке, и она улетит в свою сторону, если путь свободен. Стрелки, у которых пропала опора, падают вниз по цепочке, как домино. Очистите поле, пока не кончились ходы.

- **Кнопки-переключатели**: зоны на поле поворачивают проходящие через них стрелки на 90° или 180°.
- **Цветные замки**: часть стрелок открывается только после срабатывания переключателя.
- **Бонусы**: подсказка безопасного хода, отмена хода, +1 ход.
- **Мета**: монеты, магазин скинов и фонов, ежедневные подсказки, прогресс уровней.
- **Туториал** для новых игроков.

## Стек

Unity 2022.3 LTS · C# · URP 2D · uGUI + TextMeshPro · PluginYG2 (Yandex Games SDK) · WebGL

## Как это устроено

| Система | Как работает |
|---|---|
| Ввод | Raycast строго по слою `Arrow`; тапы поверх UI игнорируются |
| Физика стрелок | Стрелка на опоре стоит с `gravityScale = 0`. Когда опора убрана, `ReleaseSupport()` включает гравитацию, и начинается цепная реакция |
| Проверка хода | `CanExit()` проверяет путь стрелки по её текущему направлению, с учётом поворотов на переключателях |
| Отмена хода | Убранная стрелка не уничтожается, а прячется. `LevelSnapshot.Capture/Apply` откатывает позиции, направления, замки, состояние зон и счётчик ходов |
| Подсказка | Ищет стрелку, тап по которой проходит все правила. Если безопасных ходов нет, заряд не тратится |
| Уровни | Генератор уровней (`Tools → Unpuzzle`) и данные уровней в JSON |
| Редактор | Меню `Tools → Unpuzzle` собирает сцену, UI, магазин, туториал и импортирует арт и звук |

Код лежит в `Assets/Scripts`: `Core/`, `Gameplay/`, `UI/`; редакторские утилиты в `Assets/Editor`.

## Запуск

1. Откройте проект в Unity 2022.3.62f1.
2. Откройте игровую сцену и нажмите Play.
